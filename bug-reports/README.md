# Баг-репорты - "Общее дело"

**Тестировщик:** Орловский Андрей, **Даты:** 04.06.2026 - 08.06.2026
**Версия объекта:** ветка `main`, сборка от 03.06.2026 - последний коммит перед защитой

## Окружение

Windows 11, WSL2 (Ubuntu) - чтение кода объекта и запуск проверок; Git, VS Code,
Node.js, Python 3, Newman, клиент PostgreSQL 16, `sqlglot`. Стенд не разворачивался:
Docker в среде тестирования недоступен, поэтому наблюдений в браузере нет и снимков
интерфейса тоже.

Вложения к дефектам - выдержки из кода в [screenshots/](../screenshots/): в них
подсвечены строки, на которых находится дефект, а в шапке указан `путь:строка`. Это
проверяемое доказательство вместо скриншота несуществующего стенда. Для остальных
дефектов ссылку на код даёт поле **Код** и ссылки `путь:строка` в тексте.

## Метод

Дефекты найдены статическим анализом кода и сверкой контракта API. Фактические
результаты выведены из кода, а не с работающего стенда.

Каждый дефект дан в сокращённом виде и содержит поля **Дефект**, **Шаги**,
**Ожидается**, **Фактически**, **Влияние**, **Фикс**. Подробные шаги и ожидания
продублированы в тест-кейсах - ссылки на них стоят в поле **Кейсы** - и в сценариях
Newman ([api/postman_collection.json](../api/postman_collection.json)), где сценарии с
ожидаемым ошибочным поведением помечены префиксом `[KNOWN BUG]`, поэтому исправление
дефекта сразу ломает прогон. Полные листинги кода не приводятся: ссылки вида
`путь:строка` указывают в репозиторий объекта, где переход можно открыть и проверить.

Шкалы Severity и Priority определены в
[docs/methodology.md](../docs/methodology.md#3-шкалы-оценки-дефектов).

## Сводка

Всего 28 дефектов: 3 Critical, 15 Major, 10 Minor. Из них API-дефектов 15
(3 Critical, 9 Major, 3 Minor), WEB-дефектов 13 (6 Major, 7 Minor). Критических среди
WEB нет - самый серьёзный там Major, потому что все находки живут в клиентском коде и
не дают доступа к данным напрямую.

## Critical

- [API-01](critical.md#api-01-открытый-прокси-для-файлов-ssrf) - открытый прокси для файлов: SSRF во внутреннюю сеть. Эндпоинт во frontend, автотеста нет.
- [API-02](critical.md#api-02-анонимный-доступ-к-персональным-данным-и-файлам) - анонимный доступ к персональным данным и файлам. Пять запросов в папке `02 Authorization`.
- [API-15](critical.md#api-15-публичная-регистрация-позволяет-выбрать-роль-учёного) - публичная регистрация позволяет выбрать роль учёного. Два запроса плюс SQL-проверка `[U5]`.

## Major, API

- [API-03](major-api.md#api-03-невалидный-токен-возвращает-500-вместо-401) - невалидный и просроченный токен возвращают `500` вместо `401`.
- [API-04](major-api.md#api-04-нет-ограничения-частоты-запросов-на-вход) - нет ограничения частоты запросов на вход и регистрацию.
- [API-05](major-api.md#api-05-роль-фиксируется-в-токене-и-не-сверяется-с-базой-до-24-часов) - роль фиксируется в токене и не сверяется с базой до 24 часов.
- [API-06](major-api.md#api-06-нет-валидации-формата-email-и-длин-текстовых-полей) - нет валидации формата email и длин текстовых полей.
- [API-07](major-api.md#api-07-неопределённая-семантика-записи-данных) - `PUT` обновляет ресурс частично, семантика метода не определена.
- [API-08](major-api.md#api-08-фильтрация-по-тегам-клиент-вызывает-несуществующий-метод) - фильтрация по тегам: клиент вызывает несуществующий метод.
- [API-09](major-api.md#api-09-пустой-комментарий-принимается-удаление-уничтожает-ответы) - пустой комментарий принимается, удаление уничтожает ответы.
- [API-11](major-api.md#api-11-вступление-в-несуществующий-проект-завершается-успехом) - вступление в несуществующий проект завершается успехом.
- [API-13](major-api.md#api-13-тип-загружаемого-файла-определяется-по-заголовку-клиента) - тип загружаемого файла определяется по заголовку клиента.

## Major, WEB

- [WEB-01](major-web.md#web-01-сбой-загрузки-фотографии-приводит-к-дубликатам-отчётов) - сбой загрузки фотографии приводит к дубликатам отчётов.
- [WEB-02](major-web.md#web-02-подтверждение-пароля-не-проверяется-при-регистрации) - подтверждение пароля не проверяется при регистрации.
- [WEB-05](major-web.md#web-05-выход-из-аккаунта-не-очищает-персональные-данные) - выход из аккаунта не очищает персональные данные из `localStorage`.
- [WEB-06](major-web.md#web-06-переключатели-уведомлений-не-работают-и-отображаются-без-стилей) - переключатели уведомлений не работают и отображаются без стилей.
- [WEB-07](major-web.md#web-07-кабинеты-и-формы-защищены-только-на-клиенте) - кабинеты и формы защищены только на клиенте.
- [WEB-13](major-web.md#web-13-401403-приводит-к-молчаливой-повторной-загрузке-без-токена) - `401`/`403` приводит к молчаливой повторной загрузке без токена.
