# Чек-лист доступности - WCAG 2.2 AA

**Объект:** Формы, навигация, клавиатура, скринридер
**Тестировщик:** Орловский Андрей, **Заведены:** 20.05.2026, **Актуализированы:** 11.06.2026

---


## 1. Структура и семантика
- [!] Заголовок карточки профиля - `<h3>` при отсутствии `<h2>` в секции - **WEB-11**
- [!] Элемент навигации без `type="button"` внутри потенциальной формы - **WEB-11**
- [!] Декоративные SVG не скрыты от скринридера (`aria-hidden`) - **WEB-11**
- [!] Счётчики статистики - "голые" числа без доступного названия - **WEB-11**
- [x] Наличие единственного `<h1>` на странице
- [x] Иерархия заголовков не перескакивает уровни
- [x] Списки размечены семантическими тегами
- [x] Кнопки реализованы элементом `<button>`
- [x] Основная навигация размечена как `<nav>`
- [x] Изображения имеют осмысленный `alt`

## 2. Формы и подписи
- [!] `label` не связан с полем через `for`/`id` - 11 пар полей - **WEB-11**
- [!] Поисковая строка без подписи и `aria-label` - **WEB-11**
- [ ] Сообщения об ошибках связаны с полями через `aria-describedby` - **отсутствует**
- [x] Поля с `required` помечены в интерфейсе
- [x] Ошибки формы видны пользователю текстом
- [x] Ошибки перечислены в блоке ошибки, а не только цветом
- [x] Подсказки под полями читаемы

## 3. Клавиатура и модальные окна
- [!] Чекбокс не имеет видимого индикатора фокуса - **WEB-11**
- [ ] Фокус не переносится внутрь модального окна - **WEB-10**
- [ ] Клавиша `Esc` не закрывает модальные окна - **WEB-10**
- [ ] Фокус не блокируется внутри модального окна (focus trap) - **WEB-10**
- [ ] При закрытии модального окна фокус не возвращается на кнопку-инициатор - **WEB-10**
- [!] Нет `role="dialog"` и `aria-modal` - **WEB-10**
- [!] При открытии фокус не устанавливается на окно - **WEB-10**
- [!] Фон страницы прокручивается под открытым окном - **WEB-10**
- [x] Все интерактивные элементы доступны с клавиатуры
- [x] Порядок обхода соответствует визуальному порядку
- [x] Нет "ловушек" для клавиатуры
- [x] Модальное окно закрывается по кнопке
- [x] Закрытие кликом по фону

## 4. Визуальная доступность
- [ ] Проверка контраста на реальном рендере всех состояний - частично
- [ ] Поддержка `prefers-contrast` - **отсутствует**
- [ ] Поддержка `prefers-reduced-motion` - **отсутствует** при наличии анимаций
- [ ] Поддержка пользовательского масштаба 200 % - **требует проверки на стенде**
- [x] Контраст основного текста достаточен

## 5. Состояния и обратная связь
- [!] Отсутствие индикатора загрузки на страницах входа и регистрации - **WEB-09**
- [!] Состояние загрузки не объявляется для скринридера (`aria-live`) - **WEB-11**
- [!] Пользователю показывается текст внутренней ошибки - **WEB-09**

## 6. Удобство и согласованность
- [!] Подсказка о минимальной длине пароля расходится с поведением - **WEB-03**
- [!] Несогласованное написание "Отчеты" / "Отчёты" - **WEB-03**
- [!] Один статус проекта называется по-разному в трёх экранах - **WEB-08**
- [!] Переключатель статуса в модалке не содержит часть допустимых значений - **WEB-08**

## 7. Управление данными пользователя
- [!] При выходе из аккаунта персональные данные остаются в хранилище браузера - **WEB-05**
- [!] Токен хранится в `localStorage` без защиты от чтения скриптами - **WEB-05**
- [ ] Возможность сменить пароль отсутствует - **дефект продукта**
