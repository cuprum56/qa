## 1. Общий контракт и ошибки
- [!] Единый формат ошибки `{"error": "..."}` соблюдается не везде - **API-12**
- [ ] Версионирование API - **отсутствует, дефект продукта**
- [!] Пагинация в списках - **отсутствует, дефект архитектуры**
- [x] `GET /health` отвечает `200` и корректным `Content-Type`
- [x] Все ответы, включая ошибки, содержат JSON
- [x] Все UUID в ответах соответствуют формату
- [x] Все даты в формате RFC 3339
- [x] Порядок выдачи списков стабилен
- [x] Наличие заголовка `X-Powered-By` не раскрывает стек технологий

## 2. Регистрация `POST /api/users`
- [!] Некорректный email без проверки формата - **API-06**
- [!] Email длиной 256 символов -> `500` вместо `400` - **API-06**
- [!] Роль `scientist` в публичной регистрации принимается - **API-15**
- [x] Успешная регистрация -> `201`
- [x] Дубликат email -> `409`
- [x] Email нормализуется: регистр и пробелы
- [x] Пароль 5 символов -> `400`
- [x] Пароль 6 символов -> `201` (граница)
- [x] Пароль 72 символа -> `201` (граница)
- [x] Пароль 73 символа -> `400`
- [x] Роль `admin` в публичной регистрации отклоняется
- [x] Роль `volunteer` принимается
- [x] Неизвестная роль отклоняется
- [x] Пустой JSON -> `400`
- [x] Отсутствие `Content-Type` -> ошибка
- [x] Отсутствие обязательного поля -> `400`

## 3. Вход, сессия и обработка токена
- [!] Ограничение частоты запросов на `/auth/login` - **API-04**
- [ ] Refresh-токены - **не реализованы**
- [ ] Смена пароля - **не реализована**
- [!] Подделанный токен -> `500` вместо `401` - **API-03**
- [!] Просроченный токен -> `500` вместо `401` - **API-03**
- [!] Роль в токене не сверяется с базой - **API-05**
- [x] Успешный вход -> `200` и JWT
- [x] Неверный пароль -> `401`
- [x] Несуществующий email -> `401`
- [x] Сообщение о неверном пароле не раскрывает существование аккаунта
- [x] Токен содержит `sub`, `role`, `exp`
- [x] Срок жизни токена соответствует конфигурации
- [x] `POST /api/auth/logout` удаляет сессию в Redis
- [x] Токен не работает после выхода
- [x] Выход одной сессии не влияет на другие
- [x] Пустой заголовок `Authorization` -> `401`
- [x] Отсутствие заголовка `Authorization` -> `401`
- [x] Префикс `Basic` вместо `Bearer` -> `401`
- [x] Токен в формате без Bearer
- [x] Токен другого пользователя не даёт доступ к чужим ресурсам
- [x] Отсутствует заголовок `WWW-Authenticate` при `401`
